# Better Beads — 无新增幻化版本 / No Appearance Bench

基于 1.1.0-RC6，移除幻化台、幻化石、法师任务与信件、工具及普通物品外观替换，以及对应资源、文案和补丁。保留原有拼豆武器锻造台幻化。

挂画、摆件、壁纸、地板、三类武器、图纸管理、图片导入、分享、村民赠画及联机功能保留。RC6 的恢复草稿、旧分享码、赠画保护、后台解码与出血缓存修复保留。

## 构建

需要 .NET 6 SDK，以及已安装 SMAPI 的星露谷 1.6。运行 `build.ps1 -PackageTag RC6-NoAppearance -GamePath '游戏目录'`。当前版默认构建；保留完整版使用 `dotnet build BetterBeads -c Release -p:LiteBuild=false -p:GamePath='游戏目录'`。

安装包中 BetterBeads 文件夹放入 Mods；与包含幻化台的版本二选一安装，不要并存。清单版本仍为 1.1.0，保留 Nexus:53029 更新链接。联机双方必须使用同一候选版本。

此版本不读写先前幻化台的外观记录；这些记录保留在存档内，不自动清除。已获得的幻化台及幻化石在此版本没有定义，可能显示为错误物品；此前工具和普通物品幻化不再绘制。建议使用本来未使用新增幻化功能的测试存档，切回完整版本可重新读取原记录。

本次只生成本地候选包，不启动游戏，不改动 Mods、存档或线上发布。手柄、触控、联机与实际场景效果仍需游戏内验收。

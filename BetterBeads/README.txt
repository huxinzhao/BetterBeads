Better Beads 1.1.0 RC4 / 更好的拼豆 1.1.0 RC4

Updates / 更新：https://www.nexusmods.com/stardewvalley/mods/53029

Install / 安装
Requires Stardew Valley 1.6 and SMAPI 4.5.1 or a newer compatible version. Extract the BetterBeads folder into Mods. Install only one copy with UniqueID xinzh.BetterBeads.
需要星露谷物语 1.6 与 SMAPI 4.5.1 或更新的兼容版本。将 BetterBeads 文件夹解压到 Mods；不要同时安装旧版。

Play / 玩法
Reach Foraging level 2. Robin sends a letter and sells the Bead Workbench recipe. Choose Furniture (wall art, ornament, wallpaper, flooring) or Weapons (sword, dagger, hammer). Wallpaper and flooring cover one native indoor decorating area per item: 16×16 costs 20 Wood; 32×32 costs 40 Wood. Materials are taken from your backpack and ordinary chests within five tiles. Fusing does not save a design. Unsaved drafts are cached locally by save and farmer, and offered for recovery next time; recovery does not add them to the library.
觅食达到2级后，罗宾寄信并出售拼豆台配方。产品分为家具（挂画、摆件、壁纸、地板）和武器（剑、匕首、锤）。壁纸或地板每份覆盖一个原版室内装修区域；16格消耗20木材，32格消耗40木材。制作从背包及同地图周围5格普通箱子取料。熨烫不保存图纸；未保存草稿按存档与玩家单独缓存，下次打开可选择恢复，不自动进入图纸库。

Wall paintings may be given to villagers. At six hearts, supported villagers display the latest gifted painting at home from the next day. Finished pieces have a fixed appraisal; rare pieces may attract a mysterious collector. Bead weapons can provide the appearance for a compatible native forge transformation. Vertical mode adds 45° clockwise to the sword's swing and grips the bottom center of its canvas, leaving the source artwork unchanged. My designs includes a copper Sebastian standing sword template read from the game's character art.
挂画可以赠送给村民；达到6心后，适配的村民会从次日起在家中展示最近收到的画。新成品有固定估价，极少数作品会获得神秘收藏家赏识。拼豆武器可用于同类武器幻化。竖直模式在挥舞时额外顺时针旋转45°，从画布底部中央握持，静态原图不变。我的图纸中提供从游戏人物素材读取的铜制“赛巴斯 · 站立”剑模板。

Selling / 出售
New and existing Creative Mode artworks sell for 1g and can be shipped. Normal artwork keeps its original appraisal, including a legitimate zero value. Shops retain their normal purchase categories.
新旧创造模式作品售价固定1金，可出售或出货。普通作品保留原估价，包括合法零价；商店仍按原品类收购。

Online co-op candidate / 在线多人候选支持
Every player must install the same RC4 package. The host checks crafting and decorating requests automatically. Libraries and palettes are personal; nearby chests and decorated rooms are shared. Split-screen is not supported.
所有玩家安装相同 RC4 包。房主自动校验制作与装修请求。图纸、豆色各自独立；附近箱子和房屋装修状态共享。暂不支持同机分屏。

Controller and touch candidate / 手柄与触控候选
Use the D-pad or left stick to choose controls. Select the board with A; then move bead by bead, hold A to paint, or hold X to erase. B leaves the board or closes the current window. Y opens colors, LB/RB undo and redo, the right stick pans, and LT/RT zoom. Text fields offer an on-screen keyboard. Select Input Mode in Generic Mod Config Menu or edit config.json.
方向键或左摇杆选择控件，选中画板后按 A 进入逐格绘制；按住 A 摆豆、按住 X 擦除。B 退出画板或返回，Y 打开豆色，LB/RB 撤销重做，右摇杆平移，LT/RT 缩放。文字框提供屏幕键盘。输入方式可在模组设置中选择，也可修改 config.json。
In Touch mode, drag to paint and use the View button to zoom, fit the board or switch to drag-to-pan. Image import uses the imports folder. Share codes can be exported and imported as text files. Android loading and soft keyboard behavior require testing on a compatible Android SMAPI build; this package is not marked Android compatible.
触控模式拖动摆豆；“视图”可缩放、适应画布或切换为拖动平移。图片从 imports 文件夹导入，分享码可用文本文件导出和导入。安卓加载及软键盘仍需在兼容的安卓 SMAPI 上实测，本包未标记为安卓兼容。
Multiplayer still requires a real two-player acceptance session before a stable release; offline checks do not verify network latency, disconnect recovery, native inventory sync or combat visuals.
多人功能仍须进行真实双人验收后再作为稳定版发布；离线检查不能证明网络延迟、断线恢复、原生背包同步及战斗显示已经通过实测。

Compact furniture / 紧凑家具
New 16/32 paintings occupy 1×1/2×2 wall tiles with a one-pixel overlay frame. New ornaments occupy one floor row and extend upward visually. Finished paintings and ornaments have a subtle fused-bead texture. Older items keep their original dimensions and rendering.
新制16／32格画占1×1／2×2墙格，采用覆盖最外圈的一像素画框。新摆件仅底排堵路，高处为贴图；画和摆件具有轻微熨烫纹理。旧成品尺寸和外观规则保持不变。

Weapon balance / 武器数值
New weapons use connected shape, supported blade area, length and weight distribution. The original 96-bead Galaxy Sword silhouette in iridium deals 59–77 damage, slightly below its 60–80 prototype, with a 5% shorter ordinary swing. Separate beads add weight but not reach; dense or top-heavy designs can be much slower. Color and empty canvas size do not boost attributes. Existing weapons retain their frozen stats. Open the product preview for shape details, or tile-seam markers for wallpaper and flooring.
新制武器按主体形状、有效刀刃面积、长度与重量分布判定。原版银河剑的96豆轮廓使用铱材质时伤害59～77，略低于原型60～80，普通挥舞时长缩短5%。孤立豆计入重量但不增加攻击距离，密集或远端偏重图案可能明显减速。颜色及空白画布大小不提供数值加成，旧武器仍保留冻结属性。点击成品预览可查看判定说明；壁纸与地板可查看接缝标记。

Pattern editing / 图案调整
The size menu offers Move / Copy: choose the whole pattern or select an area, adjust the offset, then apply. Preview shows overwritten beads. Cancel leaves the artwork unchanged; applying is one undo step. Market appraisal is random and is not a rating of artistic quality.
尺寸菜单提供“移动与复制”：选择整幅图案或框选区域，调整位移后应用。预览会提示覆盖豆数，取消不改画板，应用可一步撤销。市场估价随机，不代表图案好坏。

Compatibility / 兼容
Version 1.1.0 keeps existing artwork and items compatible. New wallpaper/flooring use additional template IDs and save a detached pattern in each decorated location. Back up customized config.json, imports, exports, draft-recovery and edited assets before replacing an older installation. Do not remove the old mod from a running game.
1.1.0 保留旧图纸和成品兼容。壁纸、地板使用新增模板 ID，并在装修地点记录独立图案。替换旧版前请备份自定义 config.json、imports、exports、draft-recovery 与美术文件，并先退出游戏。

Editing / 自定义
Edit i18n/zh.json or i18n/default.json for text. Edit assets/art.json and the shipped PNG files for art; keep dimensions and file names. assets/gift-gallery.json controls supported home wall positions. MARD 221 codes are approximate references. Third-party resource credits and licenses are in assets.
文案在 i18n/zh.json、i18n/default.json；美术在 assets/art.json 与对应 PNG 文件中，修改时保持尺寸和文件名。assets/gift-gallery.json 控制村民挂画位置。MARD 221 色号仅供近似参考，第三方资源授权文件随 assets 提供。

This is a release candidate. Native decorating areas, replacement, save reload and two-player synchronization still need in-game acceptance checks.
本包为待发布候选版；原版装修区域、覆盖、重进和双人同步仍需游戏内验收。

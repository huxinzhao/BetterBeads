# Build

Use .NET 6 SDK, PowerShell 7 and a local Stardew Valley installation with SMAPI.

```powershell
pwsh -File ./build.ps1 -PackageTag RC6-NoAppearance -GamePath 'D:\SteamLibrary\steamapps\common\Stardew Valley'
```

Output: dist/BetterBeads-1.1.0-RC6-NoAppearance.zip. The script does not launch the game or install into Mods.
Historical code: `dotnet build BetterBeads -c Release -p:LiteBuild=false -p:GamePath=...`.
Runtime checks: `dotnet run --project tools/ForgeChecks -c Release -- "game-directory" "BetterBeads/bin/Current/net6.0/BetterBeads.dll" --no-appearance-only`.
The CPU image decode fixtures are generated by `tools/prepare-rc6-import-checks.py` (Python + Pillow).
Editors: art/editor.html and art/text-editor.html. Never commit game assemblies, caches, saves or private imports.

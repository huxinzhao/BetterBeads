## 新的拼豆流程

1. 将原料放进背包，或拼豆台周围 **横纵各5格、同一地图** 的普通箱子。无需制豆配方或采集等级，旧制豆配方会移除。
2. 选择成品。家具、摆件、雕像、椅子、桌子统一自动使用普通拼豆；服装自动使用羊毛豆；只有武器显示金属／宝石及精炼材质选择。
3. 右侧为 **4×4常用拼豆盒**。点击“拼豆染色”，先选要修改的格子，再拖动色相条和明暗／饱和度色板，确认保存16色。颜色全部自由使用，换色盒不改变已有图案。
4. 用拼豆针摆豆、取豆镊或右键取豆。盘面改为定位柱和有中心孔、明暗层次的豆粒；缩放时仍保留豆孔，并显示将要放置的半透明豆粒。
5. 检查用料并确认熨烫。先用已有豆子，再按需折算原料；确认页列出实际扣料及余豆。成品放背包，余豆合并进背包或附近箱子的可用格，空间不足则整笔拒绝。
6. 需要继续编辑时保存图纸，并正常保存游戏。常用色盒也随游戏存档保存。

例如帽子需要24羊毛豆，可用1羊毛；用1布料折36豆则留下12豆。旧木豆、硬木豆、石豆、装饰豆都能充当普通拼豆；旧成品不会被改写。

自动取料优先已有豆子。普通豆原料优先木材、石头、纤维；花卉与硬木默认保护，可在“更多”中主动开启；同来源优先低品质，品质不加产量。确认页可检查具体消耗。

武器仍保留底料、特殊效果、精炼和银河之魂。精炼需要实体豆时，先选未精炼金属／宝石材质，再用“更多 → 取豆用于精炼”。普通熨烫无需提前取豆。

完成罗宾任务后自动生成一份委托，每7个游戏日更换；交付作品换金币、友好度与季节图纸。本期提前完成后等待下一期，到期未完成的委托会替换且不扣物品；创造作品不能领奖。20张重绘参考图纸通过“更多 → 参考图纸”或图纸库筛选查看，复制后可自由改造。

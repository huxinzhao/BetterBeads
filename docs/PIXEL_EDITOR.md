# 像素编辑器：打开、画图、保存

**双击项目/编辑包根目录的`打开像素编辑器.cmd`。** 自动优先使用Edge或Chrome打开`art/editor.html`，不需要安装Node、Python或启动服务器。也可以自己用桌面版Edge/Chrome打开此HTML。

## 第一次使用

1. 点击“打开素材文件夹”，选择这个项目的根目录，或`BetterBeads`，或它下面的`assets`。
2. 在浏览器自己的提示中允许读写。权限仅用于所选文件夹；取消不会写文件。
3. 左侧选一张图，开始绘制。点“保存到原文件”或按Ctrl S，直接更新该PNG，不再下载后手动替换。

标题下面始终显示当前文件路径；连接栏显示所选目录。如果编辑的是解压后的编辑包，保存修改的就是编辑包里的图片；需要修改项目时请选择项目目录。不要把下载包里的副本误认为游戏安装目录。

## 常用操作

| 操作 | 快捷键/入口 |
| --- | --- |
| 画笔 | B，按住拖动画连续像素 |
| 橡皮 | E，或在画布上按右键 |
| 连通区域填色 | G |
| 从图片取色 | I，点击后回到画笔；点透明区域切到橡皮 |
| 撤销/重做 | Ctrl Z / Ctrl Shift Z 或 Ctrl Y；一笔作为一步，最多100步 |
| 保存 | Ctrl S，直接写回当前完整PNG |
| 调色 | 右侧色板、原生取色器或输入#RRGGBB；只改变画笔颜色 |
| 查看尺寸与细节 | 网格、缩放、“适合画布”、右侧成品预览 |
| 图集单格编辑 | “编辑范围”选某颗豆、图标、皮肤块或帽子方向 |

支持42张运行PNG，包括20张参考图纸的26个方向文件。图集可以只编辑一个格子，保存时仍写整张图集，其他格子保留；豆子/图标名称读取当前art.json的映射。宽高固定，不会把16格图拉伸成32格图。

## 保存与恢复

- 切图、换文件夹、重新载入时有未保存提示，可“保存并继续”“放弃修改”或“继续编辑”。关闭页面时浏览器也会提示。
- 每次保存先把旧PNG写入`assets/.pixel-backups`，备份名包含原相对路径和时间，以`.bak`结尾。需要恢复时，将对应备份复制回原位置并恢复为原PNG文件名，再重新载入。不会自动删除历史备份。
- 文件如果被其他编辑器改过，保存会停止，不覆盖外部修改。请先处理另一编辑器的修改，再重新载入。
- 备份/写入失败不会显示“已保存”，当前编辑保留，可重新尝试。参考图纸全透明或包含半透明像素时会提示修正。
- 浏览器不支持文件写入、拒绝权限或组织策略限制时，页面会明确提示；不会偷偷改用下载来冒充直接保存。

这是直接修改运行PNG的路线，不自动回写`art/source.json`或`art/patterns`源图。之后运行旧图集导出或源图发布脚本，可能覆盖直接编辑结果；需要长期维护生成源时，再同步到源文件。旧82图块的JSON编辑器保留在`art/source-editor.html`，从左下角链接进入。

参考图纸修改后，游戏内运行`betterbeads_reload_patterns`并重新打开参考图纸；基础贴图用`betterbeads_reload_art`。已经复制的图纸和成品不会跟着变化。编辑器不会自动启动游戏、安装Mods或修改存档。

本次验证：浏览器页面与素材搜索检查；16项定向脚本检查，包括画笔、填色、图集隔离、撤销重做、实际临时文件保存、备份一致性和外部改动冲突。文件系统句柄由测试适配器连接临时文件；浏览器原生目录选择与权限提示需用户在本机完成，没有宣称自动化走完该权限流程。

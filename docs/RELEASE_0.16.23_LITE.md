# 0.16.23-Lite：拼豆武器幻化

接入原生 ForgeMenu 与 MeleeWeapon 幻化入口。左侧保留武器本体，右侧提供当前外观；沿用原版同类型限制、10火山晶石费用及右侧物品消耗。支持原版→拼豆外观、拼豆→原版外观、拼豆→拼豆外观，普通原版组合不被接管。

## 数据与显示

- 新增武器 modData 键 `xinzh.BetterBeads/weaponAppearance`，独立记录基底武器身份、绘制物品编号和可选图案副本。不修改既有图纸／成品快照结构。
- 图案副本只有创作数据，不包含伤害、实际制作费用、附魔或售价。普通武器仍通过原版逻辑处理属性和售价；拼豆成品快照保持不变。
- 外观读取以序列化字符串为缓存依据；只有记录变化才解析，绘制标识与副本随记录缓存。纹理使用现有128项缓存和帧结束释放机制。
- `getOne()` 复制独立外观，原生锻造预览只改临时对象。已幻化图案不依赖图纸库或右侧原物品。
- 原生基底ID／外观改变使旧记录失效，成功的原生升级后清理失效记录。

## 原生锻造流程

- 原版负责支付、物品消耗及结果领取；模组不再扣一次。动画结束、原生支付之前复核配对、图案、空间与火山晶石，条件失效则停止，保留物品。
- 只替换幻化所需外观字段和独立记录，保留当前武器其他数据；准备完整记录后才写入，写入异常时恢复原外观字段。
- 本机原生解除流程会按外观物品ID重新创建右侧武器。为避免创建无图案数据的拼豆占位物，涉及模组记录时在原生已完成解除的分支清理外观，不返还外观武器或其幻化费用；宝石锻造解除和返还仍由原版执行。未参与模组幻化的原版组合完全沿用原生行为。
- 在原版说明区加入左右槽位说明、无效配对原因及解除提示；原版缺晶石、背包空间不足和制作中状态保持可见。新文案通过现有翻译接口。

## 集中验证

- 35项纯数据检查：三类图案序列化、精确像素、独立复制、过滤高级配料、身份／外观重置失效，以及损坏／未知版本／尺寸错误记录。
- 61项本机游戏程序集集成检查：原生 CanForge/Forge 和复制方法、三类武器的双向与连续换外观、保留伤害与附魔、源物品变化隔离、modData重新读取、解除恢复、错误配对、普通原版组合，以及三类各600次静止读取缓存复用。
- 集成检查注册真实 Harmony 补丁并检查原生 IL：完成解除分支只有一个外观清理入口；原生扣料和右侧消耗保留；支付前存在条件复核。
- 集成检查仅将 SMAPI 单人会话状态与16像素贴图尺寸替换为离线对象，不创建 Game1/GameRunner 或 GPU，不运行实际游戏存档。modData重建检查不能替代实际存档重进。
- Lite与完整版编译检查；安装包由现有构建脚本逐项散列校验。

## 交付及尚需实际验收

安装包：`dist/BetterBeads-0.16.23-Lite.zip`。与完整版二选一安装。

需要在游戏内确认：火山及迷你锻造台、左／右槽位预览、缺料／背包满／中途取消、扣料与右侧消耗各一次、幻化后背包／攻击显示、解除后的宝石材料返还、正常保存重进和无限武器升级重置，以及中文提示换行。

本次没有启动游戏，没有修改 Mods、存档或上一版 Nexus 宣传资料。

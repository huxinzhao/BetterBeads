# 0.16.20-Lite 操作体验优化

保留原双栏布局、材料、价格、伤害和存档结构。完整版本源码保留，完整版与 Lite 仍然二选一安装。

## 已实现

- 中键、空格＋左键平移；滚轮以鼠标位置缩放；Home 或尺寸菜单「适应画布」重新定位。窗口变化保留中心豆格与相对缩放，图纸页往返保留视角，打开另一张图纸重新适配。
- 画板当前豆格轮廓，摆豆、擦除、平移使用不同提示颜色；覆盖界面隔离反馈。小屏常用色选中后收起侧栏，松开鼠标再允许摆豆。
- Ctrl+S 保存，命名时隔离画板快捷键。保存、取色成功显示两秒；悬停约 350 毫秒后显示快捷键、被截断的文字和熨烫禁用原因。空画布、缺料、无接收空间分别提示。
- 小屏染色预览与操作栏至少 8px 间距；短按钮按剩余文字留白限制纵向压缩，不改变字体。不同页面、控件身份分别记录反馈，绘制前选择悬停目标。
- 本地配置 ReducedMotion 默认 false；HoverSounds、ClickSounds、BeadSounds、SuccessSounds 默认 true。已有 GMCM 设置入口可编辑，无 GMCM 时可改 config.json。减少动效保留颜色与轻微下沉。
- 主界面、图纸库和成品展示共用预览合成规则与 128 项缓存；按独立图纸快照、画框版本和显示方式失效。淘汰纹理在绘制批次结束后释放，返回标题清理缓存。
- 图纸库在进入或保存、复制、改名、删除后读取记录；搜索仅过滤已解析的快照。打开和修改仍检查最新记录或修订。
- 导入纯像素处理等待设置稳定 150ms 后在后台执行，可取消过时计算，只接收最新结果。保留旧预览，生成中禁用确认；加载、纹理解码和 GPU 资源操作仍在主线程。
- 用料摘要和禁用原因共用一次库存捕获；图纸变化立即刷新，库存沿用 250ms 更新周期。提交交易仍重新核对库存、空间与图纸修订。

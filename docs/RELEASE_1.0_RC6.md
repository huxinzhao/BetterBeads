# 1.0.0 RC6 · 在线多人候选与发布收尾

清单版本仍为1.0.0；联机协议为1.0.0-RC6.1。当前源码仍沿用内部 BEADS_LITE 编译开关，产品不再称Lite。

## 本轮完成

- 同版握手、工作台独占会话、心跳与退出释放；不同台可以同时使用，无房主审批界面。暂不支持同机分屏。
- 房主自动按实际操作者重算费用和属性，锁定附近普通箱子后扣料、入包、推进全局估价序号。重复请求复用已记录结果，失败恢复原料及估价进度。
- 加入者背包使用游戏原生增量序列化和发送；等待背包同步后显示成功，避免先收到成功消息就解除操作锁。已提交但网络发送异常时重发同步，不重做交易。
- 玩家各自拥有图纸、豆色、收藏、最近使用与隐藏模板。保存收到房主回执后才标记成功；只在修改时同步个人数据。
- 沿用旧 progress-lite 存储；额外 online-progress-v1 保存加入者数据与共享挂画候选。读取异常时保留旧数据并禁用联机编辑。
- 全局制作估价序号由房主旧进度延续，收藏家来信发给制作者。罗宾解锁各自判断；创造模式以房主配置为准。
- 每位村民一个共享展示位，按赠送者好感选最新合格赠画；低好感的新赠画不挤掉现有画。按实际房屋所有者选择配偶房。
- 放开现有同类武器幻化与实际持有者的战斗效果，保留原生交易和战斗入口。
- 修正小摆件成品名称、未修改保存提示；获得成品时可提示草稿未保存。减少查重中的重复排序/读取、纹理中的无用中间数组。
- 更新中英文说明、纯图片宣传与版权说明；源码保留当前版、旧完整版和美术/文案编辑入口。

## 已执行检查

- OnlineChecks：26项，覆盖个人数据隔离、共享挂画门槛/次日替换/快照、持久化及事务回滚。
- BlueprintSaveChecks：21项。
- FurnitureFinishChecks：53项。
- ForgeChecks：71项离线集成检查。
- PatchSmoke：对本机游戏程序集注册成品/家具/武器补丁，核对手持、背包、摆放及高家具绘制。
- 当前版与保留完整版编译；安装包逐项校验。构建阶段发现的错误已修复，最终结果见发布校验清单。
- 直接核对安装游戏的 NetMutex、农夫增量同步接口：原版只自动广播本机农夫，加入者背包提交因此显式使用原生增量发送。

## 仍需实际游戏验收

以上不等于真实两端联机测试。发布前仍需检查两人争用同台/同箱、加入者制作与背包同步、网络延迟和断线重进、个人图纸过夜保留、共享挂画/配偶房、收藏家信、战斗与幻化以及家具通行遮挡。地图和其他模组的交互也未在游戏里确认。

未启动游戏，未修改Mods或存档。本地Nexus/GitHub发布资料已准备，不代表已上传或正式发布。建议先作为Pre-release/候选测试包。

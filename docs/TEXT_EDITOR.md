# 拼豆文案工坊

双击项目或编辑包根目录的 **打开文案编辑器.cmd**，用 Edge / Chrome 打开。不需要安装依赖或运行服务器，也可以从像素编辑器右上角进入。

1. 点击“打开文案文件夹”，选择项目根目录、BetterBeads 或 i18n 文件夹，并允许浏览器读写。
2. 默认编辑中文 `zh.json`。左侧搜索句子或键名，也可按分类查找。
3. 点击文案后在中央直接修改，右侧对照上次保存内容。切换条目会保留草稿。
4. 点击“保存到原文件”或按 **Ctrl+S**，将当前文件的全部修改直接写回 JSON。

未连接文件夹时可以浏览内置的539条文案；连接后以磁盘实际内容为准。保存只影响当前语言文件，默认回退文案需要切换到 `default.json` 单独编辑。游戏重启后读取新文案；已有作品名称和已保存的当期委托标题不会自动重命名。

## 草稿、保护与恢复

“只看未保存修改”用于集中检查。“还原本项”恢复当前条目到上次载入或保存的内容。“重新载入”从磁盘读取整个当前文件；有草稿时会先提供保存、放弃或取消。切换文件或目录也会提示，关闭页面由浏览器提醒未保存内容。

文案键不允许编辑。请保留 `{{count}}`、`{0}`、`{0:0.##}` 等动态占位符，可以调整其在句子中的位置。编辑器检查占位符及格式、信件的 `^^` / `[#]` 标记，以及原生任务记录的固定字段；检查失败时阻止保存。文字预览用于阅读，不代表游戏内排版。

每次保存前，原文件自动备份到 `i18n/.text-backups`。恢复时先关闭编辑页，将所需 `.bak` 复制出来并改名为对应 `zh.json` 或 `default.json`，再替换原文件。备份不会进入发布包。

如果文件已被其他程序修改，保存会停止覆盖并保留草稿。先把需要保留的草稿复制到别处，再重新载入磁盘文件并合并修改。备份失败时也不会写入原文件。

## 验证范围

15项定向检查覆盖文案校验、草稿、JSON序列化、临时文件真实写入与备份、外部冲突和语言文件隔离。浏览器已检查搜索、条目切换、预览与占位符展示；目录权限对话框需首次使用时由用户完成，未自动化验证原生授权流程。没有启动游戏或修改存档、Mods目录。

维护代码：`art/text-editor.html` / `text-editor.js` / `text-editor.css`；文案规则为 `text-core.js`，保存复用 `pixel-core.js`。`art/content-tools.py` 可更新离线浏览用的 `text-data.js`；实际游戏输入仍是 `BetterBeads/i18n/*.json`。

## 英文文案（0.16.27起）

default.json为英文回退文案，zh.json为独立中文；编辑器在未连接目录时也可切换中英文预览。保存时只写回当前文件。请保留双括号命名参数和单括号数字参数，不要改键名。

# 0.16.5-Lite 改动与定向验收

此次 Lite 仅开放两种挂画和三种金属剑。完整版源文件继续保留，通过 BEADS_LITE 选择简化编辑页、图纸库和制作清单。

- `SimpleCrafting` 统一模板、材质与直接成本；预览和提交均通过 ManufacturingTransaction 的 DirectItems 分支，完全绕过折豆、余豆生成和放置。
- `BlueprintAutoSave` 在独立记录副本准备写入，保留 ID 和修订 CAS；同一未修改图纸不重复增版。
- `AtomicCraftCommit` 把原料/成品写入和图纸保存放在同一可回滚操作中。ManufacturingService 仍先冻结并重验库存、规则、箱子范围、创造模式和接收空间；交易请求成功后不能再次提交。
- Lite 编辑页支持整把剑换材、清空和撤销重做。空剑材质以已有 SupplementaryMaterials 中的零数目键记忆，不新增存档结构或真实补料；旧混合图纸在临时草稿中清理并要求重新选材。
- `SimpleEditorLayout` 提供离线检查和实际界面共用几何；整体缩放同时作用于字体、控件、绘图和点击坐标。小屏覆盖侧栏不允许穿透操作盘面。
- 两个独立 WallPicture ID 使用原生 painting 类型、单旋转状态，原有 floor picture ID 保持注册。画框合成使用独立 8×8 PNG，帧纹理失效会更新成品纹理缓存。
- 制作结果为结构化记录。成功后关闭工作台、展示一次成品；展示不发放物品，松开触发按键后才能关闭，显示出错时返回游戏并提示成功。

离线预览：small.png、fullscreen.png、drawer.png、framed-pictures.png、received.png，均在 art/lite-0.16.5。使用实际 C# 几何、已有原生 UI 参考纹理和画框合成规则；字体与游戏场景是离线示意，不是游戏截图。预览用小花仅为测试样本，不进入预设图纸或安装包。

定向检查：画的 0/1/4/5/256/1024 颗；无效替代原料；固定 4 锭与 3 档属性；背包优先及箱子顺序；接收空间；无余豆；图纸新建/更新/去重/修订冲突；注入交付中途失败后的回滚；重复提交；材质及清空撤销；旧图纸/物品；7 档尺寸的布局、遮挡和坐标换算。另使用当前安装的游戏程序集确认 painting 类型不是地面家具，并审阅原生墙面定位与旋转分支。

尚需游戏内手动验收：实际字体、手柄/鼠标/缩放输入；真实背包和箱子；熨烫单次交付与界面关闭；2×2/3×3 墙面放置预览、取下、重挂和保存重进。未改动 Mods 或存档，也未启动游戏。单人限制保持不变。

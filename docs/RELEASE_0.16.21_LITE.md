# 0.16.21-Lite 性能优化记录

本轮保留界面布局、字号、动效、图片转换效果、玩法数值和存档结构，保留完整版源码。

## 发现与处理

| 发现的重复工作 | 改动 |
| --- | --- |
| 预览已命中缓存，调用端仍创建捕获变量的回调 | 使用一次创建、接收缓存键的回调；保留 128 项上限与帧后释放 |
| 每帧测量相同按钮文字，长文字逐字符截短 | 字体测量缓存最多 1024 项、截短结果最多 512 项；按字体、字距、行距、文字、显示宽度和比例区分；素材重载与返回标题时清理 |
| UI 色值反复拆出字符串再转换 | 色值使用不分配子字符串的解析方式，并缓存最多 64 项 |
| 动效状态每帧通过筛选和临时数组清理 | 每半秒清理过期状态，复用工作列表；每帧动效计算和响应频率保持不变 |
| 工具栏每帧生成一组矩形，材料选项重复扫描画布 | 布局变化时生成工具栏矩形；同组材质按钮共用一次材质读取 |
| 去背景过程中同一像素多次进入队列 | 入队前标记和匹配，每个背景像素最多入队一次；按处理次数定期响应取消 |
| 每颗描边豆生成邻居数组和查询对象；面积采样重复计算行边界 | 按原顺序直接读取四邻居；每行共用面积和索引计算，保持原浮点运算顺序 |
| 缺失画框素材时反复读取备用资源 | 缓存备用画框，素材失效后重新读取 |

## 验证

- `--optimization-only`：127 项定向检查通过，包含缓存、导入、后台取消、反馈及相关体验检查。
- `checks/render`：79 项字体测量与截短检查通过。使用无纹理的测试字体，不启动游戏或创建图形设备；结果与原测量/截短逻辑一致，覆盖窄宽度、多行、中文字符串、字号比例、字体替换、字距和行距变化。
- 24 组尺寸、容差和半透明颜色组合，去背景与缩图像素逐格等于原算法；额外检查封闭空洞和连通通道。
- Lite 与完整版均编译通过，0 警告、0 错误；Lite 安装包 29 个条目逐项散列校验通过。
- 未重跑无关全量测试；本轮布局没有改变，没有重复生成离线效果图。

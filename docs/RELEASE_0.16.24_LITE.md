# 0.16.24-Lite：幻化兼容与缓存优化

本轮检查制作、图纸与成品读取路径，优先处理明确的状态错误和重复计算；不改变材料、售价、伤害、界面布局或存档字段。

## 修复与优化

- 武器的原生外观或身份发生改变后，已失效的合法幻化记录不再阻止它作为外观材料。重新幻化使用当前原生外观，或者已恢复的拼豆原始图案，不会重新套用过期图案。损坏记录仍拒绝作为外观来源；普通原版组合继续走原版流程。
- 成品读取缓存同时检查序列化快照和物品身份。物品身份改变而快照未变时，重新验证图案与模板是否匹配；无效组合不再复用旧图案。
- 锻造台自定义说明按文字、字体对象和可用宽度缓存排版结果。静止时复用，切换说明、翻译、字体或宽度后更新；返回标题时清理。缓存仅保留一条结果。
- 幻化提交合并配对校验与外观来源读取，避免同一次提交重复解析来源分支；提交前复核与原版扣料逻辑保持不变。

## 定向验证

- 41项数据检查通过，包含新增的600帧相同说明仅排版一次，以及文字／字体／宽度变化、清理、排版失败重试。
- 71项游戏程序集离线集成检查通过，覆盖三类武器、双向与连续幻化、属性保留、复制、错误配对、原生解除补丁，以及每类600次绘制数据缓存复用。
- 新增回归覆盖：原生重置后再次提供外观、当前外观替换、成功锻造清理失效记录、拼豆武器恢复自身图案，以及成品身份改变／恢复／快照变更时缓存刷新。
- 集成检查使用真实原生方法和 Harmony 补丁；单人会话与纹理尺寸使用离线对象，没有启动游戏、GPU或存档。不能替代游戏内视觉与保存重进验收。

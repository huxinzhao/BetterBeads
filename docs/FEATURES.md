# 更好的拼豆 0.16.4：功能与数值

美术与文案可编辑入口见[修改指南](CONTENT_EDITING.md)：参考图纸PNG外置、i18n文本及完整索引；玩法数值沿用0.16.3，旧作品不被替换。

本轮补充季节委托用途、已获得参考推荐、真实用料和奖励反馈，修复长说明截断；冬季服装未解锁时第三类为雕像。未完成项与成本分析见[玩法审查](GAMEPLAY_REVIEW_0163.md)。

本版按作者新方案改为“附近原料 → 选成品 → 16色盒摆豆 → 确认扣料与余豆 → 熨烫”。不再需要制豆配方、采集等级或颜色解锁。单人限定；以下为代码和离线检查完成范围，实机尚未运行。

## 材料和附近箱子

| 成品 | 自动／手动材料 | 用量 |
| --- | --- | --- |
| 拼豆画、摆件、雕像、椅子、桌子 | 自动普通拼豆 | max(有效图案格数, 结构预算)：画无额外预算、摆件／雕像16、椅48、桌96 |
| 帽子、无袖上衣、印花长裤 | 自动羊毛豆 | 默认24／48／72，四向不重复收费 |
| 剑、匕首、锤 | 手动金属／宝石、精炼豆，可配底料 | 默认最低16／12／24，总量含底料 |

普通拼豆沿用稳定ID `xinzh.BetterBeads.Bead.decoration`。旧木豆、硬木豆、石豆都作为普通豆库存，保留原ID防止旧物品丢失。新图纸自动记录普通豆；旧装饰图纸无论原配料是什么，重新制作时只收普通豆，不扣原有金属、宝石或羊毛。旧成品快照不重新计算。

箱子范围以实际交互的拼豆台为中心，横纵各5格，含边界，不跨地图。支持标准普通玩家箱子与大箱子，排除冰箱、特殊／共享／出货箱、自定义箱子子类和被锁定箱子。范围通过config.json中的NearbyChestRadius配置，0～20，默认5；重开工作台后应用。没有SMAPI联机支持。

背包和箱子中已有豆子优先。普通豆原料依次优先木材、石头、纤维。花卉和硬木默认不自动消耗，开启AllowValuableOrdinarySources后才依次使用；同类来源低品质优先，品质不额外增产。不使用任务物品、配方物品、有特殊modData的物品或自定义Object子类。

| 每1原料 | 折算豆子 |
| --- | --- |
| 木材、石头 | 1普通豆 |
| 硬木 | 4普通豆 |
| 纤维 | 2普通豆 |
| 花卉类别 | 4普通豆 |
| 金属矿石、金属锭 | 对应金属豆2／12 |
| 宝石 | 对应宝石豆8 |
| 羊毛 | 羊毛豆24 |
| 布料 | 羊毛豆36（在羊毛之后消耗） |

每次确认前显示实际原料与品质、用豆及余豆。举例：需要7普通豆，4纤维可折8豆，余1豆保留；帽子24羊毛豆用1羊毛，或1布料折36余12豆。余豆先合并同ID豆子，再利用背包／当前范围箱子的空格；成品只放背包。扣料会腾位，但箱子空位不能代替成品背包空间。任何一步无空间都不扣料。取消或预览没有库存副作用。

确认期间如果箱子范围、库存实例、数量、品质、规则、费用或创造模式改变，旧计划拒绝提交；创建全部替换物品后再重新检查并统一应用，异常回滚。

## 工作台布局

0.15.4采用左盘面、右侧256像素工作栏，页头显示标题与拼图／我的图纸，页脚显示状态、帮助、保存和熨烫。盘面上方为成品、拼豆针、取豆镊和更多；右栏上方豆色盒、下方用料摘要或武器材料分页。

UI视口宽小于900或高小于640时隐藏常驻右栏，通过“豆色／材料”打开最多280像素宽的覆盖侧栏。侧栏阻止背后的盘面和按钮响应，关闭回到作品。支持下限480×420，更小时显示提示。

拼豆染色常规为660×548、320方形色区；放不下时使用豆色盒／染色两页。选豆格会进入染色页，切回色盒和缩放均保留临时修改。单格还原／恢复16色为低强调操作，取消和保存始终可见。正文20、按钮18像素档位，过长名称用省略和悬停提示，不逐项缩字。

## 自由配色与拼豆盘

右侧固定4×4常用色盒，全部颜色直接可用，不再显示解锁锁头。点击“拼豆染色”，选择16格中的一格，再拖动色相条和饱和度／明暗方块。可恢复单格或默认16色；确认才保存，取消不修改色盒。色盒按存档共享，需正常保存游戏落盘。

颜色以独立RGB保存在每颗豆子中，修改常用色不会重染已摆图案或旧成品。吸管、填充和批量换色按实际颜色兼容新旧颜色ID；导入默认保留源图颜色，也可选择近似基础色盘，不限制为16种常用色。

拼豆盘改为浅色定位柱，豆子以带中心孔、边缘阴影的圆环显示。默认隐藏方格网，更多菜单可打开辅助网格。鼠标悬停空位可看到半透明待放豆粒。盘面上方使用拼豆针和取豆镊，家具／服装显示自动材料与可用量，武器才出现材料选择。小窗口下仍保留完整16色盒，武器材料支持分页。

右键取豆；Ctrl+Z／Y撤销重做；滚轮缩放；空格或中键平移。一次连续摆豆只占一步撤销。图纸另存进入新副本，旧图纸和旧成品保持独立。

## 保留玩法

可制作11种成品：拼豆画、摆件、雕像、椅子、桌子、剑、匕首、锤、帽子、无袖上衣、印花长裤。

服装尺寸：帽子四向20×20，上衣四向8×8，裤子16×16印花映射原生裤型。默认羊毛预算24／48／72，可在assets/clothing.json中设置1～9999，重启生效；新制作自动使用当前预算。旧成品不追扣材料。

精炼继续使用原生熔炉：10未精炼金属／宝石豆＋1煤炭，30游戏分钟得5精炼豆，硬度＋25%、重量不变，仅一次。需要实体豆时，武器右侧选择未精炼材质，再点“更多→取豆用于精炼”，确认原料后放入背包；每次从一个原料堆取得至少10豆或该堆现有可产量。普通熨烫无需备料。精炼豆不能由普通原料直接免费折算。

新制武器数值：铜硬度／重量3／5、铁5／6、金6／9、铱9／8；绿宝石4.5／3.2、海蓝宝石4.2／2.8、红宝石5.4／4、紫水晶3.6／3、黄水晶4.8／3.5、翡翠3.9／4、钻石6／3.5。换算公式见技术说明。

特殊豆按全部用料占比连续生效，强度为min(5×占比,1)。红宝石最多伤害＋12%、翡翠最多实际伤害吸血3%、紫水晶最多击退＋20%；20%占比封顶，无过量惩罚。普通与精炼同源合并，最多两项；新档任务先开放一个槽，再开放第二个。旧成品保持effects-1的冻结参数，旧5%吸血等效果不重算。

银河之魂每级1魂＋原生20火山晶石，最多三级，每级伤害＋10%，上限120。创造模式只免费熨烫，保持有效图案、用途和交付空间限制；颜色本来就自由。备料、精炼、工作台和锻造仍收费。

拼豆台配方仍由罗宾5000金出售，制作需木材250、石头100、铜锭5。用户要求取消的是制豆配方，不是工作台本身配方。

## 导入与边界

支持标准Object、ColoredObject、Furniture、Hat、Clothing、MeleeWeapon及本模组成品设计读取。捕获当次源图，不消耗来源。自制成品可读取全部方向和配料，不复制强化等级或最终武器属性。特殊自定义绘制、额外modData和烟熏鱼合成不宣称支持。

仍不提供联机、任意裤腿剪裁、长袖和多方向功能家具。椅子可坐、桌子可放物；服装实际动作、家具前景及导入复杂物品仍待游戏验证。

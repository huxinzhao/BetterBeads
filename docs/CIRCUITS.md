# 拼豆电路 0.2.0

这是依赖“更好的拼豆 Lite”的独立 SMAPI Mod。代码位于 `BeadCircuits.Core`、`BeadCircuits` 和 `BeadCircuits.Checks`。前置的源码、资源与安装包保持独立。

## 上手

1. 安装 Lite 0.16.34 或更新版本，再安装 `BeadCircuits` 文件夹。
2. 从罗宾处购买电路板制作台，从克林特处购买空白电路板；也可以用 `beadcircuits_bench` 命令领取实测物品。
3. 在制作台点“从示例开始”，复制“自动节拍器”或“双色闪烁与计数显示”。查看示例说明后，可调公开参数并运行预览。
4. 选择背包中的拼豆挂画或落地摆件，安装电路板。两块板的示例需要两块空白板。
5. 将作品放到场景，在制作台进入接线模式，右键来源作品，再右键同地图的音乐块或另一件拼豆作品。
6. 按住 Shift 并右键已放置作品，可查看和编辑背面电路。修改后在主菜单点“应用到已有电路板”。

示例中的音乐输出节点需要接线到原版长笛块或鼓块；音乐块沿用已调好的音高。若要改变音色，再进入接线模式，选择同一个音乐 Trigger 输出，然后右键一张可摆物品的展示台（原版桌子也可以），放入物品即可。一个输出可控制多个音乐块，共用一张展示台；换展品无需重接线。没有展品时恢复音乐块本来的声音。离开地图后时钟仍运行，声音不会在其他地图播放，也不会在返回后补播。

## 原创示范曲、创造放置与离线网页

从示例中选择“四轨小夜曲”，进入“试听多声部”即可在制作台听到旋律、低音、和声、鼓点组成的 64 步循环。试听可播放、暂停、从头播放、单步和静音单轨，使用独立时间，不要求农场先放音乐块。装入作品后，旋律、低音和和声的“旋律音符”节点分别接一块长笛块；鼓点节点接鼓块。原有 Pulse Trigger 仍能连接已经调好音高的音乐块。

制作台首页开启“创造模式”，载入示范曲或离线乐谱，再点“免费放置整套装置”。在农场选一块空的 3×3 地面，界面会用绿色或红色显示是否可放置；左键确认，Esc 取消。中心是一格 Lite 拼豆落地控制器，四周是三块长笛块、一块鼓块；电路和接线自动完成。整套装置不扣物品或金币，免费物品售价为零，并随存档保留。遇到障碍或放置失败不会覆盖原物。

浏览器打开安装包内 `offline/index.html`，可离线编辑四轨音符、休止、鼓点和速度。网页用 Web Audio 合成音试听，不包含游戏素材；复制导入码，回游戏制作台点击“导入离线乐谱”。导入后生成普通节点和 ROM，可继续在内部编辑器修改。
想快速听原始示范曲，可直接播放 `offline/demo.wav`；这是与网页相同乐谱生成的 16 秒合成音预览。

要让同一作品循环展示 Lite 图案，先选支持的 16/32 像素挂画或完整落地摆件，点“从 Lite 图案库选帧”并添加相同模板、尺寸的已保存图案。导入会复制颜色与透明像素，之后修改 Lite 原图不会改变已安装电路。图案帧节点由 Integer 序号和 Present Pulse 控制；若草稿中已有示范曲计数器，会复用它实现音乐画面同步。裁剪型 32 像素摆件变体暂不接受导入帧。

长笛块的展品对应原版手持物品音色：`(O)372/797` 贝壳、`(O)66` 竖琴、`(O)80/338/577/578` 水晶、`(O)430` 猪、`(O)444` 鸭、`(O)746/769` 玩具钢琴、`(O)382` 尘埃精灵，以及原版的 `(BC)214` 电话声。鼓块将这七组按顺序映射到 `drumkit0`–`drumkit6`。其他物品保持原音色。原版鼓块本身没有根据手持物品改变音色的机制，因此此处的鼓音色映射由扩展 Mod 提供。可在实测时按需要调整展品；电路不会改写音乐块保存的音高或鼓音色值。

## 六课教程

制作台中的“跟着做”依次介绍按钮触发、时钟、计数、ROM 显示、模块复用与跨设备连接。每课可查看提示、载入可编辑演示、检查、跳过或重来。教学草稿和虚拟输出不改动农场物品。

## 编辑器

左侧选择节点，在右侧网格点击放置。先点来源，再点目标可自动连接第一个兼容端口；拖动空白处可框选，Shift 点击可增减选区。滚轮缩放、方向键平移。双击模块进入内部；复制模块后编辑其中一个实例会创建独立定义。选中节点可调参数、增加 ROM 字、公开输入/输出或公开参数。按 F2 命名电路或公开端口。模块可以保存到存档、从模块库插入，也可以通过剪贴板分享码导入导出。

电路数据与 Lite 作品的外观快照分开保存。模块和接线记录在扩展的存档键中。删除设备或拆下板会断开外部线路。

## 离线验证与游戏实测清单

运行 `build-circuits.ps1` 会编译、运行离线检查、核对原版游戏接口、检查前置文件哈希，并生成独立 ZIP。脚本不启动游戏、不读取实际存档、不安装到 Mods。

请在游戏内实测：

- 罗宾、克林特商店价格与购买；制作台、空白板图标和物品说明。
- 16/32 像素挂画与落地摆件的安装、显示位置、拆板和重新装板。
- Clock → Counter → 多个长笛块/鼓块的同步节拍及保持原有音高。
- 同一输出连接展示台与音乐块，替换展品时长笛/鼓音色变化；拿走展品时恢复音乐块原音色。
- 原创 64 步曲目的四轨同步、制作台发声试听及静音；离线网页复制乐谱后游戏内导入。
- 创造模式在农场 3×3 空地免费放置整套装置，障碍提示、撤销与读档后保留。
- Lite 已保存图案的彩色轮播、同尺寸校验、原图修改后的副本稳定性。
- Clock → Counter → ROM → Display 的两帧切换和画框显示。
- 两个作品间的公开端口接线、移动后断线，以及背包板暂停。
- 六课教程的点击区域、中文与英文文字、菜单缩放及预览窗口。
- 保存、退出、重新读档后计数、内存、时钟相位和接线恢复。

当前内部编辑器采用基础网格与参数按钮；游戏内的菜单尺寸、点击位置和绘制顺序仍由作者实测验收。

# 0.16.3 玩法审查与本轮优化

审查依据：当前源码、默认加工规则、20张图纸实际网格、已有发布记录。结论来自代码和离线检查，尚未启动游戏。保留玩家确认的七日自动委托、自由配色和按实际豆数计费。

## 玩法循环与判断

当前循环：开台创作 → 村民故事引入工艺 → 制作家居/穿搭/武器 → 原生任务日志提示交付 → 图纸和高级工艺奖励 → 改造图纸、生活布置与战斗。故事提供一次性目标，七日委托与四季收藏提供后续目标。

| 维度 | 发现 | 0.16.3处理 | 剩余空间 |
| --- | --- | --- | --- |
| 趣味度 | 委托换了季节标题，实际用途缺少描述；完成反馈只有一句成功 | 为罗宾、格斯、艾米丽分别加入四季创作背景；奖励和下一步工艺明确呈现 | NPC故事完成后的长期个性反馈仍较少 |
| 丰富度 | 20图纸足够作为起点，但新获得图纸不醒目，冬日雪人没有对应委托用途 | 交付明确列出新增图纸，图纸库显示收集数和具体季节条件；服装未解锁时冬季第三类委托使用雕像 | 五个故事完成、四季收齐后只剩自由创作和重复委托 |
| 平衡性 | 固定委托报酬与精细图案成本并非一一对应；上衣/长裤提示曾遗漏羊毛预算 | 日志明确最低预算、推荐图纸实际豆数、固定报酬；服装读取玩家自定义整件预算 | 不把大尺寸或填满盘面当成收益倍率；暂不调整基础经济数值 |
| 游戏结合 | 已接入村民、信件、日志、熔炉与战斗，但用途提示偏通用 | 春季花园、夏日酒馆清凉装饰、秋季丰收、冬日暖屋；玩家自行选图案，不强制颜色 | 本轮未新增节日事件、村民家中实物陈列或原生送礼偏好 |
| 信息完整性 | 工坊弹窗仅绘制前五行；后半段奖励与说明可能看不到 | 长说明与选项共同分页，短列表在说明后页仍可操作 | 实机中文字体、控制器完整导航仍待核实或完善 |

## 成本核对与取舍

以下为当前默认规则下，原样复制参考图纸的真实消耗；改图后重新计费。

| 成品/用途 | 参考用豆 | 委托/故事报酬 | 判断 |
| --- | ---: | ---: | --- |
| 土豆苗小花园 | 397普通豆 | 罗宾首故事200金 | 精细收藏图不等于经济任务模板；首故事自己画32豆的小画即可 |
| 春日花束 | 386普通豆 | 格斯250金 | 也可交付16格手绘小画；不要求32格或参考图一致 |
| 花园木椅 | 329普通豆 | 椅350金 | 48只是结构预算下限，不能误报成实际图纸成本 |
| 海风茶桌 | 532普通豆 | 桌750金 | 96只是结构预算下限；图纸满细节的成本更高 |
| 帽 / 上衣 / 长裤 | 24 / 48 / 72羊毛豆 | 450 / 800 / 1150金 | 按整件预算，不按四个方向重复收费 |
| 围巾雪人 | 110普通豆 | 冬季雕像250金 | 新增对应用途，奖励和原有摆件相同 |

木材/石头默认每件1豆、纤维2豆、羊毛24豆、布料36豆。此处不把金币奖励直接当作净利润：玩家来源、品质、余豆、定制产量和原料机会成本各不相同。现有数值暂保留，避免为鼓励精细图案而诱导填满盘面刷奖励。委托提示明确“报酬固定”，推荐只从已获得且满足交付条件的图纸中选择，优先当季主题，再比较用豆量。

武器公式和旧成品保持不变；原21组武器对照仍有效。本轮没有战斗改动，不重复穷举战斗组合。参考武器目前仍主要使用铜/铁，尚未充当宝石与双特效教学配方，这是后续内容深化的具体方向。

## 已修复的未完善项

- 长委托、交付确认及完成页超过五行时被截断：现可完整翻页。
- 参考推荐可能指向未获得图纸：只推荐实际已获得、满足交付要求的图纸；没有时说明可手绘。
- 同季第二次交付仍笼统承诺图纸：奖励预览和完成页只列本次真正新增的图纸/工艺。
- 解锁详情显示内部 `season.0` / `clint` 标识：改为中文季节条件与故事名。
- 完成故事后不知道从何继续：给出次日来信、精炼入口或双特效用途。
- 已实现的功能仍残留“正在制作中/待接入”文案：替换为当前操作提示或实际配置错误提示。调试样例不视为正式美术占位。

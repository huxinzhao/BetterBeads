# 0.16.26-Lite：染色布局与图纸入口精简

## 染色界面

上一版让色格与调色板占用同一区域，需要来回切页，且右侧少量信息占用了过大的空间。本版改为同时显示色格与调色板：宽屏依次为色格、调色板、原色／新色和作品效果；小屏保留并排色格与调色板，将对照信息收至底部。

- 常用20色始终可见，修改一格时可以直接参考和选择其他颜色。作品用色超过20种时在色格区域分页，翻页不遮挡调色板。
- 点击作品颜色后直接调色，不再经过“替换此颜色／返回豆色盒”。选择当前已选色不会丢失正在对比的新色。
- 底部统一一行操作。常用色为“还原此色／恢复默认／保存豆色”；作品色为“用作画笔／还原此色／应用换色”。修改作品仍须点击应用，保留一次撤销、关闭放弃未应用修改的语义。
- 缩小整体窗口高度，收紧原色／新色对照，扩大作品效果图；小屏效果图仍可点击进入场景预览。

## 图纸入口

- 图纸库底部由四项减为“打开／改名／删除”，移除单独的复制按钮。
- 打开自己的图纸时选择“编辑原图”或“作为新图创作”。编辑原图保存后更新原记录；作为新图创作分配新ID、清空名称并保持未保存，首次保存时命名。二者的保存目标仍明确区分。
- 模板直接作为新草稿打开，不出现无意义的编辑原模板选项；原始模板和玩家已有作品不会被覆盖。
- 两种打开方式均在最终选择时复核源记录，并继续使用已有的未保存修改保护、命名取消和保存失败处理。

# Better Beads 1.0.0 RC5

新制作的16×16拼豆画占1×1格，32×32画占2×2格。外围透明留白已移除，1像素木框覆盖图案最外圈；图纸原始像素和原料计算保持完整。

新摆件按图案宽度占横向1或2格，纵向统一只占底排1格。高贴图向上延伸并沿用原版家具遮挡。已经制作、放置或赠送的作品保留旧外观与占地。

新画作和摆件增加柔和的熨烫质感。每颗豆合成4×4子像素，颜色、图纸和分享码不受着色影响。画框和空白底不带豆子纹理；图标使用较轻的细节。纹理按需生成并缓存。

美术修改入口：`assets/art.json` 的 `FusedBeadStrength`（0～1）和 `FusedBeadMask`（16个值，按4×4从左到右、从上到下排列）。遮罩值1表示保持颜色，大于1提亮，小于1压暗；允许0.5～1.5。画框继续使用 `assets/PaintingFrame.png`，新细框使用其木色与阴影区。使用已有 `betterbeads_reload_art` 命令刷新。

离线对照：`art/furniture-finish-RC5/index.html`，标注“非游戏截图”，使用模组实际合成结果与原版人物素材。安装包不包含人物贴图和预览文件。

验证覆盖新旧快照、制作出口、画框、四种摆件宽高组合、透明度及赠画兼容，并通过安装游戏程序集检查底排对齐和绘制补丁。实际通行、四向遮挡、摆放与取下仍保留游戏内验收。不自动启动游戏，不修改Mods或存档。

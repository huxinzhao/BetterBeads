# 0.16.25-Lite：创作与布置体验

## 玩家可见变化

- 拼豆染色增加作品用色页：按使用数量、RGBA稳定排序，每页20色，显示参考色号；设为摆豆色不改变20色盒，统一换色只匹配实际RGBA。原色、新色、影响数量和作品预览可在确认前查看；确认一次对应一次撤销，取消与无变化不会修改草稿。
- 两页临时调整互相保留；保存常用色、确认作品替换分别应用。关闭放弃尚未应用内容，已确认替换仍保留在编辑草稿中。
- 主界面成品格、图纸缩略图和换色效果图可打开标准场景。墙面、地板与人物读取当前游戏素材，整幅场景保持统一倍率；可放大细节。图案使用实际装框和动态摆件裁切规则，不创建世界物品或改变玩家装备。人物只是静态等比例参照，不模拟攻击。
- 图纸支持品类、收藏筛选，以及最近使用或名称排序。仅成功打开、保存、制作更新最近顺序。点击图案可预览，点击像素星形可收藏。
- 复制不再立即写入图纸库，改为打开独立未命名草稿；首次保存或制作时命名，取消不留副本。复制前复核源记录，切换继续保护当前未保存修改。

## 内部与兼容

- 仅Lite进度新增可选 `FavoriteBlueprintIds` 与 `RecentBlueprintIds`，最近记录最多100条；旧存档缺字段默认空，随正常游戏保存持久化。删除／隐藏同步清理关联偏好。不改变图纸、成品及外观快照格式。
- 精确颜色替换使用独立候选和现有撤销记录，既有按颜色ID替换入口仍留给完整版。作品用色与替换预览按编辑变化序号、源色及目标色缓存。
- 未保存身份单独作为运行状态，避免空白复制草稿被误认成已保存；保存／放弃时清除，不增加图纸字段。
- 预览复用现有128项纹理缓存及帧结束释放；挂画与摆件调用共用成品图像转换。场景资产由游戏内容管理器管理，关闭仅释放引用，不误销毁共享纹理。素材不可用时使用格线。
- 文案均通过现有翻译入口；新界面的主矩形、按钮、列表、筛选区统一由布局类提供。

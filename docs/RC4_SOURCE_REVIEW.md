# 1.1.0-RC4 源码审查记录

此份源码含尚未发布的 RC4 改动，清单版本为 1.1.0。安装包等待离线预览审阅后生成，不覆盖线上版本。未启动游戏，未修改 Mods 或存档。安卓仍为待真机验证。

## 本轮实际实现

- 以最大八方向连通部分识别主体；按握持端、保留拓扑的细化中心线和最短连通路径分配刀刃区域。回弯、镰刀和带孔图案仍计入有效区域；游离装饰只增加重量。
- 范围使用根部至最远主体边缘的直线距离，限 0.5～2 倍。弯曲路程不额外增加范围。
- 根据有效区域、全部豆数、实际长度、质量分布和静态支撑计算伤害与攻速。支撑惩罚最多20%；内部评分不显示在玩家界面。铱材质的银河参考轮廓使用原型内部攻速，新制武器额外缩短5%普通挥舞时长，实现略快而非简单加1属性。
- 尖端增加少量暴击；重复锯齿降低部分直接伤害，普通有效命中后产生3秒持续伤害；宽头锤增加最多35%击退。平滑内弧、孔洞、单个钩尖、人物的头肩手轮廓均有防误识别检查。
- 流血为6个独立半秒分期，小数累计，不给每期保底1伤害。新伤口不延后旧伤口。排除特殊攻击的叠加及重复回执；由房主推进，锁定怪物身份，不按重叠矩形寻找目标。
- 流血直接应用已计算的防御后分期金额，不再次暴击、扣防御、触发命中特效。致死使用原版 `onMonsterKilled` 处理掉落、任务及击杀归属。暂停不推进，离开所有在线玩家正在使用的地点或返回标题清理。
- 数值冻结到已有成品的 `FinalStats`，内部键为 `shapeSerration`、`shapeWave`、`shapeBleeding`、`shapeSwingTimeScale`。没有新增图纸字段或对外API；旧 `simple-1`～`simple-4` 武器不重算，幻化只替换外观。
- 画板分析按变化序号缓存，静止600帧无重复分析或新增分配。制作和预览共用计算入口。
- 联机协议更新为 `1.1.0-RC4-reliability1`，不能与其他候选规则混用。`simple-5`／`simple-6` 成品仍读取冻结伤害、攻速、范围和锯齿流血，不重新计算；`simple-6` 保留其原5%挥舞时长缩短，新成品规则为 `simple-7`。

此前已完成的 RC4 操作和装修优化同时保留：统一取色入口、确认/键盘导航、输入隔离、联机回执与库存核对、完整装修回滚、资源回收、分享目录缓存及装修质感绘制适配。

## 数值和固定参考

参考只固定数值轮廓参数，不包含游戏贴图。已从本机原版资源核对银河剑96颗、匕首74颗、锤119颗有效像素；游戏替换贴图不会改变基准。以下为原轮廓、基准尺寸的单次伤害，所有材质豆暂按相同单位重量计算。

| 类别 | 铜 | 铁 | 铱 | 基础攻速：铜 / 铁 / 铱 |
|---|---|---|---|---|
| 剑 | 14～20 | 31～42 | 59～77 | 0 / 0 / 8 |
| 匕首 | 6～10 | 13～20 | 28～39 | 0 / 0 / 3 |
| 锤 | 17～25 | 36～50 | 67～90 | −4 / −4 / −4 |

`D = D0 × (A/A0)^α × (0.8 + 0.2R)`，流血形状另乘 `1−0.1×max(Z,0.5W)`，Z为锯齿评分、W为波刃评分。低于／高于参考的 α 分别为剑0.30／0.15、匕首0.35／0.10、锤0.35／0.25。

`B = a log2(N/N0) + b log2(L/L0) + c log2(clamp(Q/Q0,0.25,4)) + 16×clamp((N−256)/768,0,1)²`。剑系数2／4／1，匕首2／6／0.5，锤2.5／4／1.5。负担为正时全部减速，为负时只给一半加速；额外减速上限26，加速上限剑/匕首4、锤3，最终攻速限−20～8。追加密集重量项从256豆之后连续增长，1024豆增加16点负担，不依赖画布尺寸。

当前示例：92豆直剑和等豆数弯剑均57～74伤害、攻速7；112豆镰刀状剑60～78、攻速5；1024豆满格铱剑84～110、攻速−18。此类计算是像素形状启发式，不是材料力学模拟，任意图案仍可能需要后续调优。

### 银河原型的实际属性核对（2026-10-01）

新增 `tools/ForgeChecks/GalaxyBalanceChecks.cs` 的 `--galaxy-balance` 检查，直接只读加载本机 `Data/Weapons` 与 `TileSheets/weapons`，以原生斜向16格轮廓和铱材质制作。对照原生 `MeleeWeapon` 实例，同时验证实际制作快照、序列化往返和成品实例属性一致；不创建游戏实例或读取存档。数据记录在 `art/weapon-shape-1.1.0-RC4/galaxy-comparison.json`。

| 原型 / 豆数 | 原版伤害 → 拼豆伤害 | 原版攻速 → 拼豆攻速 | 原版击退 → 拼豆击退 | 原版暴击 → 拼豆暴击 |
|---|---|---|---|---|
| 银河剑 / 96 | 60～80 → 59～77 | 8 → 8 | 1 → 0.92 | 2% → 2.136% |
| 银河匕首 / 74 | 30～40 → 28～39 | 3 → 3 | 1 → 0.72 | 2% → 3% |
| 银河锤 / 119 | 70～90 → 67～90 | −4 → −4 | 1 → 1.053 | 2% → 2% |

攻速为物品内部属性，不是说明面板的换算值或百分比。三者暴击倍率均3，范围倍率均1，均没有锯齿流血。平均单次基础伤害分别为原型的97.14%、95.71%、98.13%。本轮按用户授权校准了攻速；降低三档锤的基础击退至0.70／0.74／0.78，保留最多35%宽头形状加成，使银河锤轮廓为1.053，而不是之前的2.025。暴击与伤害不变。

核对原版 `setFarmerAnimating` 的实际指令：基础挥舞时长为 `400−speed×40`，然后叠加玩家速度与武器速度增益，剑／锤／匕首再各自分帧。银河剑属性8→9将基础时长80→40，因此拒绝直接+1方案。新成品在现有 `FinalStats` 字典保存 `shapeSwingTimeScale=0.95`，仅在普通挥舞入口、玩家增益之后、原版分帧之前缩短一次时长；原型形状名义频率约提高5.26%，实际受帧率和游戏动画限制。时长最低40以保护极端增益；不缩短特殊攻击冷却，不增攻击次数。原版物品和 `simple-1`～`simple-5` 成品不应用该倍率，幻化保留左侧冻结倍率；制作确认及中英文成品说明显示“挥舞时长−5%”。

### 其他原版形状与效果建议

`--native-shape-survey` 覆盖本机67张原版武器及工具贴图，包含弯刀、波刃、骨剑、三叉戟、细针、棍棒、宽头锤、煎锅和三种镰刀；不把弹弓或镰刀工具的原功能加入成品。全部按同一铱材质分析，另计算铜／铁，不能把高阶材质克隆的伤害与低阶原型数值直接当作不平衡。每张图逐一验证制作与保存往返后的原生成品属性；居中放入24、32格画布不改变数值，空白空间不提供属性。

发现并修复铱镰刀像素阶梯的锯齿误判：齿距一致性容差由50%收紧至30%，排除直线／对角步交替导致的√2齿距比例。三种镰刀均无流血误触发，人工重复锯齿仍可触发；弯刀的弧线及孔洞保持有效面积与直线范围规则。Infinity形状与其对应Galaxy轮廓相近，因此不会仅凭颜色继承无限武器的强化；猫咪剑亦不会继承原版弹射效果。

值得后续实测的形状效果：长细尖刺可考虑小幅穿甲（不直接复制原版铱针的高暴击），钩刃可考虑轻微牵引，叉形可考虑轻微破防。尚未添加以上效果；不对分叉图案增加攻击次数，避免与匕首连刺和锤特殊攻击叠加。当前使用尖端暴击、可靠重复锯齿／波刃流血和宽头击退。

## 构建与复现

需要 .NET 6 SDK、本机合法安装的星露谷与SMAPI引用。源码包不含SDK、游戏程序集、提取的原始纹理文件、存档、配置缓存或安装包；原版图案只出现在标明“非游戏截图”的审阅对照PNG中。`native-summary.json` 不含原版像素，重生成该PNG需运行原版形状检查读取本机游戏素材。

```powershell
dotnet build BetterBeads/BetterBeads.csproj -c Release -p:GamePath='你的游戏目录'
dotnet build BetterBeads/BetterBeads.csproj -c Release -p:LiteBuild=false -p:GamePath='你的游戏目录'
dotnet run --project checks/lite -c Release -- --geometry-only
dotnet run --project checks/lite -c Release -- --large-weapons-only
dotnet run --project checks/lite -c Release -- --localization-only
dotnet run --project tools/ForgeChecks -c Release -p:GamePath='你的游戏目录' -- '你的游戏目录' 'BetterBeads/bin/Current/net6.0/BetterBeads.dll'
dotnet run --project tools/ForgeChecks -c Release -p:GamePath='你的游戏目录' -- '你的游戏目录' 'BetterBeads/bin/Current/net6.0/BetterBeads.dll' --shape-only
dotnet run --project tools/ForgeChecks -c Release -p:GamePath='你的游戏目录' -- '你的游戏目录' 'BetterBeads/bin/Current/net6.0/BetterBeads.dll' --galaxy-balance
dotnet run --project tools/ForgeChecks -c Release -p:GamePath='你的游戏目录' -- '你的游戏目录' 'BetterBeads/bin/Current/net6.0/BetterBeads.dll' --native-shape-survey
```

两个版本共用部分中间文件，请顺序编译。内部 `LiteBuild` 名称用于保留旧完整分支，当前产品不以Lite对外命名。版权沿用 ©2026 xinzh，All rights reserved；第三方保留各自许可。不要把本源码ZIP直接放进 Mods。

## 波刃流血增补（2026-10-01）

- 剑与匕首以主刀刃的横截面重心重复转折识别蛇形／波刃；不根据颜色、武器名称或图案ID硬编码。排除单个平滑弧线和钩尖，锤不参与。
- 采用至少三次显著转向及细长刀身门槛，中心线变化须超过0.55格；能识别Wicked Kris在同一侧的连续两个波峰。该判定仍为像素轮廓启发式，不保证任意低分辨率图案均可识别。
- 流血强度为 `max(锯齿评分,0.5×波刃评分)`，两种特征不叠加两份伤害。普通有效命中的防御后非暴击伤害作为预算基准，持续3秒；单纯波刃最多追加15%，直接伤害最多扣减5%。亡灵／机械免疫、史莱姆半效、联机房主结算沿用现有规则，不增加特殊攻击判定次数。
- 实际Wicked Kris轮廓：69豆，波刃评分0.5118446，流血强度0.2559223，约追加7.68%基准伤害。统一铱材质为27～38伤害／攻速2／范围1.19；直接伤害由28～39稍降。估算不含暴击、装备与怪物差异，整数分期总伤害可能更低。
- 67张原版贴图中仅Wicked Kris取得波刃评分；银河三件、弯刀和三种镰刀均不误触发。所有轮廓检查了实际制作、快照往返、24／32格空白扩展数值一致；规则升级后旧6版挥舞倍率和范围保留。
- 本轮集中完成97项几何、67个原版图案制作／重读、83项幻化接口、4项流血生命周期、25项中英文检查，当前与保留完整版编译均无警告、无错误。555项大武器和其他既有检查沿用上轮通过记录，未重复运行。
- 镰刀牵引与三叉戟破甲仍为方案候选，尚未实现；不把原版工具的收割功能加入拼豆剑。

# 0.16.22-Lite 原生风格成品获得展示

完成制作后关闭拼豆台，以原版举物姿势配合原生 `DialogueBox` 展示成品，替换原来的大面板、标题与完成按钮。场景继续可见，头顶显示玩家实际作品，保留装框挂画与武器外观；下方显示作品名、已入包及图纸保存提示，武器另显示快照伤害。沿用原生对话的逐字出现、继续标记、鼠标及手柄操作。

特殊物品获得音效使用本机游戏原版的 `getNewSpecialItem`，遵循成功音效开关。减少动效时不播放作品的轻微上浮。必须先释放制作输入，且展示至少约 450 毫秒后才能继续；退出和紧急关闭恢复原姿势，不修改玩家移动或冻结标记。

本地只读检查确认 `Farmer.holdUpItemThenMessage` 使用第 57 帧举物姿势；其内置展示按物品 ID 取图，并存在特定物品效果分支。因此本版本复用姿势与原生对话框，以现有成品绘制入口展示实际图案，不调用星之果实食用或属性变化流程，也不再次发放、消费物品或保存图纸。

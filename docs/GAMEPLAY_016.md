# 0.16.3 工坊玩法与取舍

本轮增加四季用途提示、已获得图纸推荐、实际预算与准确奖励反馈；修复长说明截断。未开放服装任务时冬季第三类为罗宾雕像，原订单不变。具体成本审查与未完成项见[0.16.3审查](GAMEPLAY_REVIEW_0163.md)。以下基础数值继续沿用0.16.1。

这一版把自由创作接到村民生活与战斗成长中。颜色、手动绘图、基础服装和家具始终自由；任务奖励提供创作主题和高级工艺，不收回旧档已经使用的能力。

## 为什么这样调整

| 方面 | 原问题 | 本版处理 |
| --- | --- | --- |
| 趣味度 | 做完作品后缺少用途和后续目标 | 村民故事、每周交付、四季图纸，让作品有去处 |
| 丰富度 | 主要依靠玩家自己想图案 | 20张可修改参考图纸，涵盖家居、服装、武器、季节主题 |
| 生活平衡 | 服装消耗高，少量像素家具过便宜 | 服装24／48／72豆；家具收结构预算，与像素数取较大值 |
| 战斗平衡 | 宝石同时提供高伤害与轻量优势，超量特效突然转为惩罚 | 降低宝石硬度、提高金豆硬度；特殊收益连续增长、20%封顶 |
| 游戏结合 | 高级工艺缺少学习过程 | 罗宾、艾米丽、克林特、马龙分别引导生活、服装、金属、实战 |
| 使用体验 | 自动原料可能消耗珍贵花卉、硬木 | 默认保护；玩家可明确开启，已有普通豆照常使用 |

不以每日打卡推动进度。故事没有期限；委托每7个游戏日刷新，周次数限制用于控制经济收益，昂贵配料不额外涨报酬。

## 工坊故事

首次打开工作台的次日出现首封信，后续任务在前置完成的次日出现。信件和原生任务日志可查看要求；带作品去找对应村民，在交付确认页提交。普通手持礼物仍走原生送礼。

| 任务／村民 | 前置与交付 | 奖励 |
| --- | --- | --- |
| 第一件手作／罗宾 | 首次开台次日；消耗至少32像素的拼豆画 | 200金、50友好度、2图纸、每周委托 |
| 把作品穿出去／艾米丽 | 罗宾之后；消耗四向各至少8像素的帽子 | 350金、50友好度、2图纸、服装委托 |
| 金属也能拼／克林特 | 罗宾之后，与服装线独立；展示铜／铁及对应精炼豆合计至少60%的武器 | 武器归还；25友好度、2图纸、1个特效槽 |
| 耐热试验／克林特 | 金属任务之后；背包交付2铁锭、1煤炭 | 25友好度、2图纸、熔炉精炼 |
| 真正派上用场／马龙 | 精炼任务之后；用非创造模式拼豆武器实际击败10怪 | 2图纸、双特效、银河之魂强化；无友好度奖励 |

不把图案画得像模板作为领奖条件，符合种类与像素／材质要求即可。检测武器不收走，其他作品交付会消耗明确选中的背包物品。

## 每周委托与图纸

- 完成罗宾首个任务后，每个固定七日周期自动抽出一份委托：罗宾家居、格斯挂画，或艾米丽服装（尚未开放时为罗宾摆件）。连续两期不会出现同一类；每期最多领奖一次。
- 到期未完成的委托会被新委托替换，不扣物品；提前完成后等待下期。读档不重抽，任务日志显示剩余天数。
- 奖励：画／摆件250金、椅350金、桌750金、帽450金、上衣800金、裤1150金，每份75友好度。家具各视图至少16像素、挂画32像素、服装各视图8像素。
- 每个季节首次完成委托获得两张主题图纸，四季共8张，后续年份不重复发相同图纸。
- 参考图纸共20张：入门2、五个故事各2、四季各2。入口在“更多 → 参考图纸”或图纸库筛选。可查看大图、方向、来源与用料，复制成独立图纸后改造；未获得模板不限制手绘相同图案。
- 创造模式生成的作品不能兑换任务或委托奖励，调试样品同样排除。创造模式不会免费领取任务奖励。

## 制作与数值

帽子／上衣／裤子预算24／48／72羊毛豆。1羊毛24豆，1布料36豆；先用已有豆，再用羊毛、布料，余豆保留。普通作品按 `max(像素数, 结构预算)` 计费：画没有额外结构预算，摆件／雕像16、椅48、桌96。空图仍不能制作。

武器伤害规则版本为weapons-2，特效为effects-2。金豆硬度由4变6，重量9；七种宝石硬度调整为绿宝石4.5、海蓝宝石4.2、红宝石5.4、紫水晶3.6、黄水晶4.8、翡翠3.9、钻石6，重量不变。铜、铁、铱不变。

选中的宝石特效强度 `min(5×同源豆占全部材料比例,1)`：红宝石最多增伤12%、翡翠最多实际扣血吸血3%、紫水晶最多击退20%。普通与精炼同源合并，最多选择两项；没有过量惩罚。吸血不足1生命的余量累计，满血清空，击杀溢出伤害不计。

代表性结果：铜剑15～21、铁剑25～35、金剑30～42、铱剑45～63、钻石剑30～42且速度+1；80%铁＋20%红宝石剑28～40。完整21组基础与混合配料见[对照表](../checks/balance-0.16.0.csv)，没有穷举所有配料。

精炼仍为10豆＋1煤炭，30游戏分钟产5精炼豆，硬度×1.25、重量不变。银河之魂仍最多3级，每级1魂＋原生20火山晶石，伤害逐级增加10%，上限120。拼豆台配方与售价不变。

## 兼容与交付边界

旧成品沿用存储的属性、强化等级和特效，不按新硬度重算。旧模组存档补齐进度字段时直接保留全部旧高级能力；仍可体验故事并获取图纸。新安装本模组的存档从入门开始。

processing.json的旧默认硬度迁移到新值，自定义数值／产量保留，迁移前备份。服装旧默认80／120／160逐项迁移为24／48／72，自定义预算保留。成品快照schema不变，工坊进度按版本迁移，旧版已接委托保留至本期结束，旧版本期已领奖不会重复发放。

交付冻结当天、选中物品与任务状态，确认时复核；扣料和奖励一起提交，异常恢复本次物品、金币、友好度和进度。重复点击不能再领，取消没有物品副作用。所有进度仍需正常游戏保存。

本版仅完成离线检查与接口核对，没有启动游戏。实际信件显示、NPC对话、击杀统计及旧档加载仍需按PROGRESS.md中的三条路径验收；不宣称完成了实机测试。

# Better Beads 1.0.0 RC3

熨烫现在只制作成品，不要求命名或自动保存图纸。未命名成品显示对应的品类名称；制作后仍可在本次游戏会话中重新打开拼豆台继续编辑草稿。若要把图纸保留到游戏存档，需主动点击“保存图纸”并正常保存游戏。

手动保存时会检查作品内容。与已有图纸完全相同的作品直接关联已有记录，不再创建副本；已有图纸未修改时不增加修订。图纸名称、色号名称和参考底图不参与内容比较，颜色按精确 RGBA 比较。

定向检查覆盖了图纸复用、内容差异、修订冲突和不含图纸写入的制作事务。当前版及保留完整版均已编译。文件选择、实际制作和游戏内显示仍需在游戏中验收。本包不自动安装，也不修改 Mods 目录或存档。
